# Samples Directory

Place sample video files here for testing.

## Recommended test videos:
- Hindi dialogue video with burned-in Devanagari subtitles
- Kannada dialogue video with burned-in Kannada subtitles
- Mixed language video for multi-language testing

## Notes
- Supported formats: MP4, MKV, AVI, MOV
- For best OCR results, use videos with clear, high-contrast subtitles
- Videos with subtitle font size ≥ 20px work best with the default crop settings
